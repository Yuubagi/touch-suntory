# Touch! SUNTORY userscript

Touch! SUNTORYのブラウザ起動・認証更新・JAN登録を補助する非公式userscriptです。

[![userscriptをインストール](assets/install.svg)](https://raw.githubusercontent.com/Yuubagi/touch-suntory/main/touch-suntory.user.js)

## インストール

1. お使いのブラウザにuserscript管理拡張機能（Tampermonkeyなど）を導入し、有効にします。
2. 上の **「インストール」ボタン** を押します。
3. 管理拡張機能の確認画面で内容を確認し、インストールします。

ソースコードが表示される場合は、管理拡張機能が有効か、対象サイトでスクリプトの実行が許可されているかを確認してください。必要に応じて、管理拡張機能のURL指定インストールから[スクリプトのURL](https://raw.githubusercontent.com/Yuubagi/touch-suntory/main/touch-suntory.user.js)を開いてください。

## 使い方

1. 通常の入口からTouch! SUNTORYを開き、ログインします。
2. スキャンボタンの位置に表示される **「自動登録」** を押すと、スクリプト内のJANコード5件を順に送信します。
3. 実行中にもう一度押すと、現在の通信が完了した後に残りの送信を停止します。

結果は画面下部に表示されます。認証期限が切れている場合は、ブラウザでの認証更新を試みます。再ログインやミニアプリの開き直しが必要な場合は、表示に従ってください。

## 動作について

- LINEの案内画面では、対象の「ブラウザで開く」リンクが見つかった場合に自動移動します。
- JAN登録には、対象ページのログイン情報と入口URLの`hs`パラメーターを使用します。
- 登録先API、対象ホスト、JANコードはスクリプト内に定義されています。
- 実際に購入した対象商品の登録に使用し、サービスの利用条件に従ってください。サントリーおよびLINEの公式ツールではありません。

## 更新

更新先として、このリポジトリの`main`ブランチを指定しています。管理拡張機能の更新確認を利用するか、インストールボタンから再度開いて更新してください。

不具合は[Issues](https://github.com/Yuubagi/touch-suntory/issues)へ報告できます。認証情報や個人情報は投稿しないでください。
